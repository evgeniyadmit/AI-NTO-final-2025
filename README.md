
🐅 Реайди амурских тигров по паттернам окраса с ConvNeXt-XL

Решение для идентификации амурских тигров по уникальным паттернам окраса шерсти.
Бейзлайн построен на архитектуре ConvNeXt‑XL, backbone Zhuang Liu.

🔎 Что сделано
 • Обучение классификатора на изображениях тигров (ID по паттернам полос).
 • Тонкая донастройка ConvNeXt backbone (XL).
 • Собственный бейзлайн для быстрого старта.
 • Метрики и визуализация предсказаний.
 • Лёгкая, воспроизводимая структура пайплайна.

🚀 Как запустить

pip install -r requirements.txt
python train.py

📊 Метрики (baseline)
 • Топ-1 accuracy (ID): хороший стартовый уровень (F1 Accuracy = 0.79; с небольшими доработками)
 • Визуальное распознавание полос: сильно индивидуально

📁 Структура, которая имелась в этом соревновании
├── data/                # train/val images
├── models/              # weights after training
├── train.py             # training loop
├── infer.py             # prediction script
└── requirements.txt     # dependencies

💡 Примечание
Это лёгкий стартовый бейзлайн, цель — удобная адаптация под кастомные данные и эксперименты с augmentations, head-слоями и loss-функциями для улучшения Recall/Accuracy.
